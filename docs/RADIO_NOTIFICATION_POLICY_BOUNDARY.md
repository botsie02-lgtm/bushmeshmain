# Notification policy boundary

The native Android/Android Auto publisher BushMeshCarNotifications is shared by native frame handling and the JS native-car bridge. It runs before durable local association. Native notification IDs, sender grouping, actions and receipt policies are slot based. Do not suppress by slot, name, last selected conversation or a cached PSK. The same radio could have been externally reconfigured; background frames lack an original PSK generation. Do not delay native notifications behind JavaScript or issue an additional notification from the history consumer.

Implemented: a non-secret native global preview boolean, committed synchronously and read by the existing shared publisher on each new notification. The body and MessagingStyle body are both redacted; channel name remains visible. Existing notifications already posted are not retroactively rewritten. OS notification settings and independent critical alert policy remain unchanged. Foreground and native background use the same presentation policy. Ordinary JS speech retains exact-incarnation policy and now supports a persisted one-hour mute with expiry and explicit cancellation.

Deferred: native per-chat mute, timed native mute and per-chat preview require one authoritative receive identity and native verified association before notification publication; unknown associations must retain global policy. Do not invent a slot-based approximation or duplicate JS notification. Android Auto reply actions also need independently verified destination generation before a stronger notification design is enabled.
